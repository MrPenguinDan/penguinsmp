💻 Minecraft Java Edition (PC / Mac / Linux)
  1. Launch the standard Minecraft Launcher and boot up your game (Version 1.20 or newer is recommended for full compatibility).
  2. On the main game menu, click on the Multiplayer selection button.
  3. Look toward the bottom-right corner of your screen and click on the Add Server button.
  4. In the Server Name text field, type a profile title you'll recognize, such as PenguinSMP.
  5. In the Server Address box, carefully type or paste your server IP: ://penguinsmp.com
  6. Click the Done button at the bottom to save your configuration profile.
  7. Locate the new entry in your multiplayer list, click it once to highlight it, and select Join Server to log in.
📱 Minecraft Bedrock Edition (Consoles, Mobile & Windows App)
  1. Open Minecraft on your device (Xbox, PlayStation, Nintendo Switch, iPhone/iPad, Android device, or the Windows Store App).
  2. Click the main Play menu option and look at the tabs along the top. Select the Servers tab.
  3. Scroll past the featured servers entirely. Scroll all the way down to the bottom of the page and click Add Server.
  4. Fill out the three required configuration profile boxes exactly as follows:
    • Server Name: PenguinSMP
    • Server Address: ://penguinsmp.com
    • Port: 19132
  5. Click the Save button to add it permanently to your quick-access list, or hit Play to join instantly!
Console Players Notice (Xbox, PlayStation, Switch): Console platforms naturally block third-party custom servers. To bypass this restriction and join, download free community apps like Bedrock Together or MC Server Connector on your mobile phone while connected to the same Wi-Fi network.
