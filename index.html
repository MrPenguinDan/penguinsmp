🐧 Welcome to PenguinSMP! 🐧

Follow the simple guide below to connect and play with us on both Java and Bedrock editions.

Server IP: ://penguinsmp.com
Bedrock Port: 19132

How to Join (Minecraft Java Edition)

  1. Launch Minecraft Java Edition (Version 1.20+ recommended).
  2. Click on Multiplayer from the main menu.
  3. Click the Add Server button at the bottom.
  4. Enter PenguinSMP as the Server Name.
  5. Type ://penguinsmp.com into the Server Address box.
  6. Click Done, select the server, and click Join Server!

How to Join (Minecraft Bedrock / Windows / Mobile / Console)

  1. Launch Minecraft Bedrock (PlayStation, Xbox, Switch, iOS, Android, or Windows 10/11).
  2. Click Play and navigate to the Servers tab.
  3. Scroll all the way down to the bottom and click Add Server.
  4. Set Server Name to: PenguinSMP
  5. Set Server Address to: ://penguinsmp.com
  6. Set Port to: 19132
  7. Click Save or Play to jump right in!
